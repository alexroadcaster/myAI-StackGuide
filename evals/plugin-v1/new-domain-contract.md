# CP-04 new-domain challenge

Freeze twelve new scenarios, exact canonical identities, routes, query terms,
requirement/context partitions and upstream sources before running unchanged
ranking modules. Preserve the active bundle, prior declarations and captures.

Each scenario has one source-supported useful target, not an exhaustive set of
relevance judgments. Other candidates remain unjudged. Report actual target
rank, coverage in the first twelve and survival into the evidence pack; do not
calculate full Recall, nDCG or precision by assigning zero to unknown results.
This same-author prospective challenge is not independent held-out acceptance.

Compare active FTS5, original literal scoring, separated capability/context
scoring and both existing priority modes. Declare literal adapters separately
from observed FTS5 scores. Verify candidate bytes against the frozen receipt
before the evaluation-only pack seam; production retrieval and packing must
reject the unactivated candidate. Re-execute the ten historical fully judged
development cases for the conservative mode and retain any regressions.

Input English technical terms test catalog matching for Russian project goals.
They do not prove natural Russian query translation, semantic reasoning,
integration feasibility, implementation time or end-user explanation quality.
Nearby taxonomy peers are alternatives requiring verification, not presumed
negatives. No model/provider activation or parent CP-04 closure is authorized.
